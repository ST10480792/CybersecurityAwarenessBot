# Cybersecurity Awareness Chatbot

## Project Overview
The Cybersecurity Awareness Chatbot is a C# console application designed to educate South African citizens about cybersecurity awareness and online safety.

The chatbot provides users with information about important cybersecurity topics such as:

- Password Safety
- Phishing Scams
- Safe Browsing
- Suspicious Links
- General Cybersecurity Awareness

The chatbot interacts with users in a conversational manner, provides personalised responses, and includes a voice greeting and ASCII art for a more engaging experience.

---

## Features
This chatbot includes the following features:

- Voice greeting using a WAV audio file
- Cybersecurity-themed ASCII art logo
- Personalised user interaction
- Conversational chatbot experience
- Cybersecurity awareness education
- Input validation for invalid or empty entries
- Typing effect for chatbot responses
- Colourful and structured console interface
- GitHub Actions Continuous Integration (CI)

## How to Run the Project

1. Open the project in Visual Studio.
2. Build the solution.
3. Run the application.
4. Enter your name to begin chatting.
5. Ask cybersecurity-related questions.

Examples:
- What is phishing?
- Tell me about password safety
- What is cybersecurity?
- How are you?
- What can I ask you about?

To leave the chatbot, type:

exit

or

bye
